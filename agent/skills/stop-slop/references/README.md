# References

The full reference files (`phrases.md`, `structures.md`, `examples.md`) live in the upstream Stop-Slop repo:

https://github.com/hardikpandya/stop-slop/tree/main/references

To include them in this scaffold, clone or download them from upstream into this directory. We do not vendor them here to avoid shipping stale copies of someone else's work.

```bash
cd agent/skills/stop-slop/references
curl -O https://raw.githubusercontent.com/hardikpandya/stop-slop/main/references/phrases.md
curl -O https://raw.githubusercontent.com/hardikpandya/stop-slop/main/references/structures.md
curl -O https://raw.githubusercontent.com/hardikpandya/stop-slop/main/references/examples.md
```
